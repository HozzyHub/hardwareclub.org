Repair, upgrade or replace?

A rule of thumb, a few cheap fixes that work wonders, and the signs it's time to let go.

Start with what's actually wrong

SymptomLikely causeUsually worth fixing?
Slow to start and slow to open thingsOld spinning hard drive, too little memoryYes. An SSD is the single best upgrade for most older machines.
Dies when unpluggedWorn-out batteryOften, if a replacement for that model is available at a fair price.
Hot, loud fan, random shutdownsDust, dried-out thermal pasteYes. Cleaning is free; paste is a few dollars.
Cracked screenPhysical damageDepends on the model. Check replacement panel prices first.
Won't chargeBad charger, damaged charging portTry another charger first. Port repairs vary a lot.
No longer gets security updatesSoftware support endedMaybe: a lightweight Linux install can extend its life. See Linux on an old PC.
Water damage, bent board, burnt smellBoard-level damageRarely. Donate it for parts.

A simple rule of thumb

If the fix costs more than about half the price of a decent used replacement, or the machine can't do what you need even when fixed, move on. If it costs very little and fixes the problem, fix it: the most sustainable computer is the one that already exists.

Cheap upgrades that make the most difference

  1. Replace a hard disk with an SSD.
  2. Add memory to at least 8 GB for everyday browsing and office work.
  3. Clean out dust and, if you're comfortable, renew the thermal paste.
  4. Reinstall the operating system for a clean start (after backing up).

The upgrade guide shows how.

When to let it go

Once a device is more trouble than it's worth, don't leave it in a drawer: old electronics don't get more valuable and batteries degrade. Run the donate, repair, or recycle tool, or offer it to us. Broken is fine. We'll test it, reuse what works, and responsibly recycle the rest.
