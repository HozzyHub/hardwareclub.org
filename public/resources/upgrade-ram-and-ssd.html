Upgrade memory and swap in an SSD

The two upgrades that make an old computer feel new again, and how to do them without breaking anything.

Before you buy anything

  1. Identify the exact model. It's printed on the underside label or shown in the system information page. Search the model number plus "service manual" or "upgrade". The maker's manual and iFixit guides show how to open it.
  2. Check if parts are replaceable. Many thin laptops and nearly all recent Macs solder the memory to the board, and some solder or lock the storage.
  3. Match the memory type. DDR3, DDR4 and DDR5 are not interchangeable, and laptop (SO-DIMM) and desktop (DIMM) sticks are different sizes. Check how many slots you have and the maximum supported.
  4. Match the storage connector. A 2.5-inch SATA SSD fits where a laptop hard disk went. Some machines take M.2 (SATA or NVMe, which differ). The service manual tells you which.

The swap

  1. Back up. Then decide whether to clone the old drive or do a fresh install (fresh is usually cleaner on an old machine).
  2. Power off, unplug, and remove the battery if it's removable. Hold the power button for ten seconds to drain residual charge.
  3. Ground yourself. Touch bare metal on the case before touching components, and hold boards and sticks by their edges.
  4. Swap the part. Memory clicks in at an angle and snaps flat. Drives slide into their connector and fasten with a small screw or caddy.
  5. Reassemble, boot, and check in the system information that the new memory and drive show up.
  6. Install the operating system from a USB drive (see the Linux guide for a free option), or restore your clone.

Test before you trust it

  • Run MemTest86+ for a full pass to catch bad memory.
  • Check a drive's health with SMART data (smartmontools or the built-in tools). Used drives with reallocated sectors should not hold anything important.

Common mistakes

  • Buying the wrong memory generation or form factor.
  • Forcing a stick that isn't aligned with its notch.
  • Losing tiny screws: sort them into a muffin tin or an egg carton.
  • Pulling a swollen battery. If the case is bulging, stop and read the battery guide.
