Resources / Linux on an old PC

Guide · Intermediate

Give an old PC a second life with Linux

A free, supported operating system can keep a computer that Windows has left behind useful for web, email, documents, video calls and more.

Why bother

Microsoft ended support for Windows 10 on October 14, 2025, and Windows 11 requires newer hardware features (such as TPM 2.0) that many older but perfectly capable machines lack. Mainstream Linux distributions keep receiving security updates on that same hardware and are free.

Choose a distribution

DistributionBest for
Linux MintFirst-timers coming from Windows. Familiar layout, works well on modest hardware (the Xfce edition is lightest).
UbuntuLarge community, lots of tutorials, long-term-support releases.
Fedora WorkstationNewer software, quick updates, good for tinkerers.

As a rough guide, 4 GB of memory is comfortable for everyday use and 2 GB can work with a lightweight desktop. An SSD helps far more than a faster processor does.

Try it without installing

  1. Download the ISO from the project's own site and verify its checksum if they publish one.
  2. Write it to a USB stick (4 GB or more, and everything on it will be erased) with a tool such as balenaEtcher, Rufus on Windows, or Fedora Media Writer.
  3. Restart and open the one-time boot menu (often F12, F10, Esc or Option, depending on the maker). Choose the USB stick.
  4. Pick "Try" (or the live session). Check that Wi-Fi, sound, the camera, the trackpad and the screen work.

Install

  1. Back up your files. A full install replaces whatever is on the disk.
  2. Choose "erase disk and install" for a clean machine, or install alongside Windows if you have free space and want both. Turn on disk encryption if the laptop travels.
  3. Finish setup, install updates, and you're done.

If something doesn't work

Wi-Fi chips, fingerprint readers and some graphics cards are the usual trouble spots. Search the exact model with the distribution name. Many issues have a known fix, and the live session tells you before you commit to anything.
